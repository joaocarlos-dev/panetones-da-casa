# Panetones da Casa

Landing page em React para divulgação do Kit Família.

## Executar localmente

```bash
npm install
npm run dev
```

## Configurar o WhatsApp

O número já está configurado como `5516991348643`, com código do país e DDD. Para trocar no futuro, edite `WHATSAPP_NUMBER` em `src/main.jsx` e atualize também os links `data-whatsapp` do `index.html` se ele continuar sendo aberto diretamente por duplo clique.

Os botões usam a mensagem: `Olá! Vim pelo site dos Panetones da Casa e gostaria de fazer um pedido. Pode me informar os sabores disponíveis e a entrega?`

Depois, execute `npm run build` para gerar a versão de produção.
